### Advent of Code 2025

My solutions to [Advent of Code 2025](https://adventofcode.com/2025) - in Python and C++.
In some cases, the Python code is used to prototype and get a result simply by solving the puzzle, without too much code optimization.

#### C++:
To compile and run, include the number of the day as a command line argument, e.g., `make run NUM="02"` for day 2.

**NOTE:** the input is user-/account-dependent.
